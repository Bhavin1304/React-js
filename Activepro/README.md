# React Bootstrap Website

A simple responsive website built with **React** and **Bootstrap 5**, featuring a **Navbar, Carousel, Album, and Footer**.

---

## 🚀 Features
- ✅ Responsive **Bootstrap Navbar**
- ✅ **Bootstrap Carousel** for hero section
- ✅ **Album/Grid layout** for showcasing items
- ✅ **Footer with social links, navigation, and subscription**
- ✅ Organized into reusable React components

---
