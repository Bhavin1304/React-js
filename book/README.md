#  About  
This component allows you to add a book (title & author), edit existing entries, and delete them—all with JavaScript’s state management (via `useState`). It’s a great starting point for learning React’s basic CRUD operations.

##  Installation
```bash

git clone https://github.com/your-username/books-component.git
cd books-component

# Install dependencies
npm install

# Run the app
npm start
````

---

## Usage

After launching, type the book’s **title** and **author**, then click **Add Book**. To update an entry, click **Edit**, modify the inputs, and hit **Update Book**. To remove a book, press the **Delete** button.
