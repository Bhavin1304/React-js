#  Books Component

Manage your list of books in a simple React component.

##  Project Overview

This small React component allows you to **add**, **edit**, and **delete** books, each with a title and author. It’s a great demonstration of managing arrays of objects and form state in React.

##  Features

-  Add new books with title and author  
-  Edit existing book entries  
-  Delete a book from the list  
-  Dynamic rendering of the book list  

##  Installation & Usage

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/books-component.git
   cd books-component
````

2. Install dependencies:

   ```bash
   npm install
   ```
3. Run in development:

   ```bash
   npm start
   ```
4. Open your browser at `http://localhost:3000` to see it in action.

## How to Use

* Type the **book title** and **author** into the input fields.
* Click **Add Book** to add it to the list.
* To modify an existing entry, click **Edit** next to a book — the form will populate with its details. After adjusting, hit **Update Book**.
* To remove a book, click the **Delete** button next to it.
