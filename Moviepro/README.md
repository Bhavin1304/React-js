
# 🎬 Favorite Movies App

A simple and interactive React app to manage your favorite movies. Users can add, update, and delete movies, and the data is stored in the browser's local storage for persistence.

---

## Features

- Add new movies with a title and optional details.
- Edit existing movies.
- Delete movies you no longer want in your list.
- Persistent storage using `localStorage`.
- User session management (placeholder component included).
- Responsive and visually appealing UI with Tailwind CSS.
- Smooth animations and gradient backgrounds for a modern feel.

## Getting Started

### Prerequisites

- Node.js >= 14
- npm or yarn

### Installation

1. Clone the repository:

```bash
git clone https://github.com/yourusername/favorite-movies-app.git
cd favorite-movies-app
````

2. Install dependencies:

```bash
npm install
# or
yarn install
```

3. Start the development server:

```bash
npm start
# or
yarn start
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Project Structure

```
src/
├── components/
│   ├── MovieForm.js      # Form to add a new movie
│   ├── MovieList.js      # Displays list of movies
│   └── UserSession.js    # Handles user session info
├── App.js                # Main app component
└── index.js              # Entry point
```

---

## Usage

1. Open the app in your browser.
2. Use the **Movie Form** to add a new movie.
3. Manage your movie list via **Movie List**:

   * Edit any movie.
   * Delete movies you no longer want.
4. Movies will persist even after refreshing the page.
