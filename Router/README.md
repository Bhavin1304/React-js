## 🚀 Features

* **Navigation** between Home, About, Projects, Contact, and Cart pages.
* **Product listing** on the Home page (data comes from `json/products.js`).
* **Add to Cart** functionality with state management using React hooks.
* **Cart page** to view and manage selected products.
* **Dynamic Routing** for product detail pages.

## 🛤️ Routes

| Path        | Component     | Description       |
| ----------- | ------------- | ----------------- |
| `/`         | Home          | Displays products |
| `/about`    | About         | About page        |
| `/projects` | Projects      | Projects page     |
| `/contacts` | Contact       | Contact page      |
| `/products` | ProductDetail | Product details   |
| `/carts`    | Carts         | Shopping cart     |
